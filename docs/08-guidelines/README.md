# 📖 08 — Nhóm Tài Liệu: Quy Chuẩn Lập Trình & Đào Tạo (Guidelines & Pedagogy)

Thư mục này tập hợp các tài liệu mang vai trò **quy chuẩn kỹ thuật viết mã, phong cách lập trình Clean Code, và cẩm nang phương pháp học tập dành cho kỹ sư Backend Laravel**.
